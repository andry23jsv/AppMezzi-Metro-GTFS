# AppMezzi - GTFS Metro Roma

Repository pubblico dedicato al dataset GTFS statico delle sole linee metro utilizzato dall'app AppMezzi.

**Fonte dati:** feed GTFS statico ufficiale di Roma Mobilita. Il dataset filtrato viene generato automaticamente dagli orari ufficiali e non rappresenta dati in tempo reale.

I file pubblicati dall'automazione saranno `dist/metro_static_gtfs.zip` e `dist/metro_static_gtfs.zip.md5`.

Il repository contiene solo dati e strumenti di generazione; il codice dell'app rimane nel repository privato AppMezzi.
